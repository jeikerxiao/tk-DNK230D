> 建议先跟完标准例程打基础，再用综合例程学"如何把知识组织成大工程"。

## 1. 开发板简介

**DNK230D（K230D BOX）** 是正点原子推出、基于嘉楠 **K230D** 芯片的 AI 视觉开发板：

| 项目 | 说明 |
| --- | --- |
| 主控芯片 | 嘉楠 K230D，**RISC-V** 架构双核处理器 |
| AI 算力 | 内置 **KPU**（神经网络加速器），约 6TOPS |
| 开发方式 | **CanMV IDE** + **MicroPython**，无需写 C |
| 显示 | 2.4 寸 MIPI 屏 + 电容触摸 |
| 摄像头 | 两路 MIPI CSI（双摄） |
| 应用场景 | 人脸识别、物体检测、手势识别、循迹小车、语音唤醒、图形桌面等 |

> [!NOTE]
> **名词速查（零基础必看）**
> - **RISC-V**：一种开源免费的处理器指令集架构，可理解为"芯片听得懂的语言标准"，与 ARM 类似。
> - **KPU**：K230D 里专门跑 AI 神经网络模型的加速器，比 CPU 算 AI 又快又省电。
> - **TOPS**：每秒万亿次运算，衡量 AI 算力的单位。
> - **MicroPython**：跑在单片机 / 嵌入式芯片上的精简版 Python，语法与 Python 3 基本一致。
> - **CanMV**：嘉楠官方的 MicroPython 开发框架；**CanMV IDE** 是配套电脑端工具（写码、下载、调试、看摄像头画面）。
> - **LVGL**：开源嵌入式图形界面库，综合例程的整个桌面就是用它画的。

## 2. 硬件组成与接线注意

K230D BOX 由 **CNK230DF 核心板**（K230D 芯片、内存、SD NAND）+ **DNK230D 底板**（屏幕、摄像头、按键、LED、蜂鸣器等外设）组成。

**底板外设清单：**

| 外设 | 规格 / 引脚 |
| --- | --- |
| LCD 显示屏 | 2.4 寸 MIPI 屏，640×480，带电容触摸 |
| 摄像头 | 两路 MIPI CSI |
| 按键 | KEY0=GPIO34、KEY1=GPIO35、KEY2=GPIO0（KEY2 兼启动模式选择） |
| LED | 双色：红=GPIO61、蓝=GPIO59 |
| 蜂鸣器 | 无源，PWM 驱动（GPIO60） |
| 存储 | TF 卡槽 + 板载 SD NAND |
| 串口 | UART（IDE 通信 / 打印 / 与单片机通信） |
| 音频 | 板载麦克风（录音、语音唤醒） |

> [!WARNING]
> **接线避坑（新手必读）**
> - **摄像头 / 屏幕 MIPI 排线插反会烧坏**：触点面朝向底座触针，**必须断电插拔**，插好轻拉确认锁紧。
> - **供电用 5V/2A 及以上**：AI + 屏幕 + 双摄同时工作电流大，供电不足会反复重启、IDE 掉线。
> - **扩展 GPIO 是 3.3V 电平**，切勿接入 5V 信号；ADC 引脚只能接 0~3.3V。
> - 运行 AI 例程时**发热属正常**，不要遮挡散热面。
>
> 更详细的硬件说明见 [标准例程 README · 硬件介绍](./标准例程-CanMV版/README.md#2-硬件介绍)。

## 3. 环境准备（IDE + 固件 + 连接）

1. **装 CanMV IDE**：从嘉楠 CanMV 官网或正点原子资料盘下载 **CanMV IDE（K230D 版）**，按提示装好串口驱动。
2. **烧固件**：二选一——① 烧到板载 **SD NAND**（脱机可用，推荐）；② 烧到 **TF 卡**（方便换固件）。用官方烧录工具完整烧录，不是简单拷文件。
3. **连接**：用 **Type-C 数据线**（不能是纯充电线）连板子与电脑，打开 IDE 点左下角连接按钮，选对应串口；连接后底部显示固件版本即成功。

> [!WARNING]
> **固件与 IDE 版本必须匹配！** 版本不匹配会出现"能识别串口但连不上板子"。请用正点原子资料盘配套的 IDE + 固件组合。
>
> **综合例程还需注意固件大版本（v1.2 / v1.3）**，选错会导致 RTC 时间设置异常，详见[综合例程 README · 第 11 节](./综合例程-CanMV版/README.md#11-v12-与-v13-的区别)。

完整的环境准备 / 烧录 / 串口排查步骤见 [标准例程 README · 前置环境准备](./标准例程-CanMV版/README.md#3-前置环境准备)。

## 5. 学习路线（分门别类）

推荐按下面 **6 个阶段**由浅入深。阶段 1~5 都在[标准例程](./标准例程-CanMV版/README.md)里，阶段 6 是[综合例程](./综合例程-CanMV版/README.md)。

### 阶段 1 · 基础外设入门

学会控制 LED、蜂鸣器、按键，理解 GPIO、FPIOA、定时器、串口等嵌入式最基础概念，最后点亮 LCD。

> 跑马灯 → 蜂鸣器 → 按键输入 → WDT → Timer → 呼吸灯 → RTC → UART → thread → LCD → 触摸屏

### 阶段 2 · 摄像头与图像基础

第一次让摄像头画面出现在屏幕上，学习在图像上画线画框、颜色阈值追踪。

> 摄像头 → image 元素绘制 → 边缘检测 → 直线/线段/圆形/矩形检测 → 单/多颜色识别 → 色块计数 → 色块追踪 → 文件读写 → 拍照

### 阶段 3 · 特征识别

识别具有特定图案特征的目标：循线、二维码、条形码、AprilTag、DM 码。

> 快速线性回归（循线）→ 黑线循迹 → 二维码 → 条形码 → AprilTag → DM 码

### 阶段 4 · KPU AI 推理

用 K230D 的 KPU 运行 AI 模型：人脸、人体、手掌、手势、物体检测与分割、车牌识别。

> 人脸检测 → 人脸关键点 → 人脸姿态 → 人脸识别 → 人体检测 → 人体关键点 → 跌倒检测 → 手掌检测 → 手势识别 → 手掌关键点 → 手掌关键点分类 → 动态手势 → 局部放大器 → 物体检测 → 物体分割 → 车牌检测 → 车牌号识别

### 阶段 5 · 单点综合项目

把前面的知识组合成完整小应用。

> 猜拳游戏（手势 + 游戏逻辑）→ 关键词唤醒（音频 + AI）→ 自分类学习（在线训练）→ 录音机 → 视频播放器

### 阶段 6 · 产品级综合工程（综合例程）

学完前面所有知识点后，来看**如何把它们组织成一个完整产品**：一个带锁屏、桌面、状态栏、多 APP、AI Hub 的 LVGL 图形系统。

> 读懂 GUI 架构 → 体验 8 个内置 APP → 用 AI Hub 一键运行 19 个 AI 演示 → 照着 Template 扩展自己的 APP

**在此基础上你还能做出**：视觉循迹小车、人脸门禁、姿态互动装置、带图形界面的 AI 面板等。

## 8. 常见问题 FAQ

**Q1：IDE 连不上开发板？** 换数据线（很多 Type-C 线只能充电）、重装串口驱动、确认固件与 IDE 版本匹配、按复位后重连。

**Q2：摄像头黑屏 / 报错？** 断电检查排线方向与松紧、确认代码里 sensor 设备号与实际接口一致、检查供电是否充足。

**Q3：屏幕不亮？** 检查屏幕排线、确认 LCD 初始化参数与例程一致、确认脱机脚本保存位置（`/sdcard/main.py`）。

**Q4：AI 例程报模型加载错误（打不开 .kmodel）？** 模型是否已放到 `/sdcard/examples/kmodel/`、传输是否完整、固件是否过旧。

**Q5：综合例程拷进去黑屏 / 不进桌面？** `/sdcard/main.py` 是否存在、`/sdcard/CanMV Sample/` 是否完整且**未改名**、固件版本与工程版本（v1.2/v1.3）是否匹配、供电是否足够。

**Q6：画面识别卡顿、帧率低？** AI 推理比普通图像算法耗时属正常；可降低分辨率或缩小 ROI 提速；确认模型跑在 KPU 上。

**Q7：一运行就复位 / 重启？** 供电不足（换 5V/2A 以上）、内存不足（关掉多余大图预览 / 降分辨率）、若启用了 WDT 例程则喂狗超时会主动复位（预期行为）。

> 更细分的 FAQ：[标准例程 FAQ](./标准例程-CanMV版/README.md#7-常见问题-faq) ｜ [综合例程 FAQ](./综合例程-CanMV版/README.md#12-常见问题-faq)
